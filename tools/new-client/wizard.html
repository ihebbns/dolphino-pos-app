⚡ Servio — Nouveau client

Créez un nouveau POS complet en quelques minutes, à partir d'une base existante.

1. Type de commerce

Chaque type charge la base de code adaptée (impression cuisine, stock, scan code-barres...) et, pour le commerce, un catalogue de départ à modifier.

2. Identité du client

3. Fonctionnalités & moyens de paiement

Activez uniquement ce dont ce client a besoin — tout le reste reste dans le code (désactivable plus tard) mais n'apparaît pas à la caisse.

4. Menu / Catalogue

Il n'y a pas de lecture automatique de PDF/photo intégrée à cet outil (pas d'IA branchée ici). En revanche : envoyez le PDF ou la photo du menu à Claude dans la conversation — il peut lire l'image/PDF et vous générer directement le JSON ci-dessous, prêt à coller. Sinon, ajoutez les catégories à la main.
📋 Importer un menu (coller le JSON généré par Claude)

5. Zones de cuisine (impression)

Assignez chaque catégorie à une zone d'impression. Une zone = une imprimante physique possible. Choisissez "1 seule zone" pour un ticket cuisine unique, sans répartition.

6. Vérification & création
